# Output Templates

Templates for the four artefacts generated by the `project-bootstrapping` skill.
Substitute all `[PLACEHOLDER]` values from interview answers before rendering.
Scan output for any remaining `[PLACEHOLDER]` strings — flag any that could not
be filled and ask the user before proceeding.

Generation order: FRAMING.md → CLAUDE.md → TASKS.md → system prompt.
Each file is confirmed and written before the next is generated.
FRAMING.md must pass the framing gate before CLAUDE.md is generated.

- Default output format: [FORMAT_DEFAULTS]

## Task Formatting Rules

When converting S7Q21 raw lines to TASK entries:

1. Number sequentially: TASK-001, TASK-002, …
2. Restate as verb + object if the raw line is a goal ("have a working pipeline" → "scaffold pipeline structure")
3. Infer `target` from the description — file path or component name if determinable; else "TBD"
4. Set `scope` to `[REPO_NAME]` for all initial tasks
5. Place all entries in `## 🔴 Backlog`
